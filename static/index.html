Mistral

Per usare i modelli Mistral con una chiave personale.

Apri Mistral Studio ↗
  1. Apri Mistral Studio e accedi o crea un account.
  2. Apri “API Keys”, scegli “Create new key” e assegna un nome.
  3. Copia subito la chiave: il valore completo viene mostrato una sola volta.
  4. Torna qui, seleziona Mistral, incolla la chiave e salva.

OpenCode Zen

Gateway OpenCode con modelli verificati e pagamento a consumo.

Apri OpenCode Zen ↗
  1. Apri OpenCode Zen e accedi con il tuo account.
  2. Aggiungi un metodo di pagamento o eventuali crediti.
  3. Crea o copia la tua API key dalla pagina Zen.
  4. Seleziona OpenCode Zen qui, lascia l’indirizzo proposto, incolla la chiave e salva.

Google Gemini

Gemini tramite Google AI Studio e la sua API compatibile OpenAI.

Apri Google AI Studio ↗
  1. Apri Google AI Studio e accedi con il tuo account Google.
  2. Nella pagina API keys scegli “Create API key” e collega un progetto.
  3. Copia la chiave e controlla i limiti o la fatturazione del progetto.
  4. Torna qui, seleziona Google Gemini, incolla la chiave e salva.

Anthropic Claude

Claude usa l’API Messages ufficiale di Anthropic.

Apri Claude Console ↗
  1. Apri Claude Console e accedi o crea un account.
  2. Vai in “Settings → API keys” e scegli “Create key”.
  3. Dai un nome, scegli la scadenza e copia la chiave.
  4. Torna qui, seleziona Anthropic Claude, incolla la chiave e salva.

NVIDIA NIM

Endpoint NVIDIA compatibile OpenAI con modelli ospitati e lista modelli automatica.

Apri NVIDIA Build ↗
  1. Apri NVIDIA Build e accedi o crea un account NVIDIA.
  2. Scegli un modello, apri la sezione API e crea una API key.
  3. Copia la chiave e torna qui: l’endpoint NVIDIA NIM è già compilato.
  4. Seleziona NVIDIA NIM, premi “Browse Models”, scegli il modello e salva.

Kilo Gateway

Un endpoint compatibile OpenAI per molti modelli con una sola chiave.

Apri Kilo Gateway ↗
  1. Apri Kilo e accedi o crea un account.
  2. Apri il profilo personale e raggiungi la sezione della chiave API.
  3. Copia la chiave e aggiungi crediti se il modello lo richiede.
  4. Torna qui, seleziona Kilo Gateway, incolla la chiave e salva.

Provider personalizzato

Per un endpoint OpenAI-compatible che conosci già.

Esempio: chiavi OpenAI ↗
  1. Scegli “Provider personalizzato”.
  2. Inserisci l’indirizzo base HTTPS senza aggiungere “/chat/completions”.
  3. Inserisci il nome esatto del modello e la chiave API.
  4. Salva e prova “Solo organizza”.
