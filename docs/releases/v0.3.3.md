## Italiano

Release senza Pocket TTS, con Kokoro offline senza account.

- Windows x86-64: scarica il file `.exe`.
- Linux x86-64: scarica il file `.AppImage` e rendilo eseguibile.
- macOS Apple Silicon: scarica `.dmg` oppure `.app.zip`.
- Installazione automatica di Python, OCR, Kokoro, FFmpeg e LFM al primo avvio.
  Richiede Internet; dopo la preparazione puoi usare la modalità offline.
- Corretto il primo avvio Linux/macOS e il recupero di installazioni interrotte.
- Registrazione in-app e menu delle voci clonate per i provider opzionali
  supportati. Kokoro non effettua clonazione.
- README dettagliato italiano/inglese e installazione con una riga per sistema.
- Controllo release automatico all'avvio e ogni 12 ore, più pulsante manuale;
  se è disponibile una versione nuova, l'app mostra il download per Windows,
  Linux o macOS.
- Pulsante MP3 subito dopo la generazione e nomi file distinti per ogni traccia.
- Su Windows, l'EXE aggiornato si installa nella cartella utente e crea o
  aggiorna il collegamento nel menu Start per avviare la copia installata.
  Le aperture successive usano così la nuova versione senza PowerShell.

Le versioni precedenti alla 0.3.3 non includono ancora il controllo automatico:
per passare a questa versione serve un primo aggiornamento manuale. Dalla 0.3.3
in poi gli aggiornamenti futuri vengono segnalati nell'app.

Le build sono sottoposte a test nativi di installazione, OCR e sintesi vocale
prima della pubblicazione. Sono incluse somme SHA-256, sorgente dell'app,
sorgenti dei runtime e avvisi delle dipendenze installate.

**Avvertenze:** pacchetti senza firma commerciale; macOS non notarizzato.
Nessuna garanzia assoluta di sicurezza o conformità normativa.
LFM ha una licenza con limite commerciale di fatturato; Fish locale opzionale
ha termini di ricerca/non commerciali. Consulta il README e le licenze prima
di redistribuire. Non sono inclusi documenti, chiavi o campioni dell'autore.

## English

Pocket TTS has been removed. Standard offline speech uses Kokoro without an account.

Download the Windows x86-64 `.exe`, Linux x86-64 `.AppImage`, or Apple Silicon
macOS `.dmg` / `.app.zip`. First launch automatically prepares Python, OCR,
Kokoro, FFmpeg and LFM and requires Internet. Offline processing is available
after setup. Incomplete setup is retried on the next launch.

Includes in-app recording and saved-clone selection for supported optional
providers, one-command installers and a detailed Italian-first/English README.
Kokoro does not clone voices.

The app checks GitHub Releases on startup and every 12 hours, and provides a
manual update check. When a newer package is available, it links to the package
for Windows, Linux, or macOS. Versions older than 0.3.3 need this first update
installed manually; later releases can be announced in-app.
On Windows, opening the downloaded EXE installs it in the user's local app-data
folder and creates or refreshes the Start menu shortcut to launch that copy.
Open the app from the Start menu for future launches; these use the new version
without a PowerShell update step, and the local data directory is preserved.

Native installation/OCR/speech tests gate publication. SHA-256 checksums,
application source, runtime sources and installed dependency notices are included.
Packages are not commercially signed or notarized. No security or regulatory
certification is claimed. LFM has revenue-related commercial restrictions;
optional local Fish has research/non-commercial terms. Read the licenses.
