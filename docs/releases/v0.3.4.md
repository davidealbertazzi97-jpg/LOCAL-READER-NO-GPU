Release 0.3.4 fixes Windows installation and side-by-side launches.

- Each Windows version keeps its own executable and Start menu shortcut.
- A newer version no longer replaces the previous executable.
- Running versions use distinct local launcher tokens and ports while sharing
  the local history and settings.
- The launcher checks the server version before reusing a running process.
- Windows first-run downloads use Windows certificate validation, and the
  signed Microsoft Visual C++ x64 runtime is installed only if missing.
- The content policy allows the app's update check to call the official GitHub
  Releases API.
- Includes the audio download button and automatic release checks from 0.3.3.

Windows x86-64 package was built in a Windows 11 Quickemu VM and installed and
tested in a separate headed Windows 11 Quickemu VM. See `SHA256SUMS.txt` for
package hashes.
