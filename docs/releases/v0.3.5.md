Release 0.3.5 includes the Windows install and side-by-side fixes.

- Each Windows version keeps its own executable, launcher configuration and
  Start menu shortcut. Versions use separate local ports and tokens while
  sharing history and settings.
- First-run Windows downloads use Windows Schannel and verify the fixed size
  and SHA-256 for model/runtime archives; the launcher validates and installs
  Microsoft's signed x64 Visual C++ runtime when needed.
- The launcher checks server version before reusing a running process.
- The update checker can reach the official GitHub Releases API.
- Includes the audio download button and automatic release checks from 0.3.3.
- The native package smoke-test PDF now uses Pillow's bundled font, so the
  release check does not depend on a system font installed by the runner.

Windows x86-64 was built in a Windows 11 Quickemu headless VM and tested in a
separate headed Windows 11 Quickemu VM. The binary in this release is the
Quickemu-tested build. See `SHA256SUMS.txt` for package hashes.
