Local Accessibility Studio 0.3.6 aggiorna nome e logo dell'app, mantenendo le
funzioni della versione 0.3.5: OCR, revisione del testo, riordino locale,
sintesi vocale online con recupero automatico e Kokoro offline.

Per avviare la versione Windows, aprire l'EXE con un doppio clic. La prima
esecuzione richiede Internet e diversi minuti per preparare Python,
dipendenze e modelli; la console mostra le fasi di installazione. Se manca
il runtime Microsoft Visual C++, Windows richiede l'approvazione UAC per
installare il componente firmato da Microsoft. L'EXE dell'app non ha firma
commerciale e SmartScreen può mostrare un avviso.

L'installer crea la propria copia versionata e il collegamento
"Local Accessibility Studio 0.3.6" nel menu Start. Nella VM sono stati avviati
contemporaneamente Local Reader No GPU 0.3.5 e Local Accessibility Studio
0.3.6, verificando porte, accessi autenticati e collegamenti distinti.

Entrambi i pacchetti finali, Windows e Linux, hanno superato le prove reali
di sintesi italiana offline e del percorso completo PDF, OCR, testo,
revisione, riordino locale e generazione audio. Sono passati anche i 58 test
automatici e tutti i controlli di `scripts/check.sh`.

Le prove riguardano Ubuntu 26.04.1 x86-64 e una VM QEMU Windows 11 x64
10.0.26300.9457. Non certificano tutte le build, gli aggiornamenti o le
configurazioni hardware Windows 11. I dettagli e i checksum dei pacchetti
locali sono in [v0.3.6-validation.md](v0.3.6-validation.md). I pacchetti della
release pubblica sono ricostruiti e verificati dall'automazione GitHub:
per i loro checksum usare il file `SHA256SUMS.txt` allegato alla release.

---

Local Accessibility Studio 0.3.6 updates the product identity and Windows app icon.

- Windows keeps separate versioned executables, Start menu shortcuts, launcher
  settings, ports and tokens, so this app can run alongside earlier releases.
- The one-file launcher verifies its embedded app payload, installs its pinned
  runtime and starts without requiring Python or administrator rights. It asks
  for standard UAC approval only when Microsoft’s signed Visual C++ runtime is
  missing.
- The logo is included in Windows, Linux and macOS packages.

The Windows package was built and tested in a QEMU Windows 11 x64 VM
(10.0.26300.9457). A first install copied the EXE into its versioned package
folder, created its Start menu shortcut, completed the runtime and model
bootstrap, and started the local health endpoint successfully. This checks
that VM’s installation path; it does not certify every Windows 11 build or
hardware configuration.

The final Linux and Windows packages passed offline Kokoro speech and the
complete OCR, text, review, reflow and speech smoke tests. Both the public
0.3.5 app and the new 0.3.6 app ran simultaneously with separate authenticated
ports and Start menu shortcuts. All 58 unit tests and the complete project
checks passed. See the [validation report](v0.3.6-validation.md).
