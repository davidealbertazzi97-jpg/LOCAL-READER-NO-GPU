# Roadmap

Implemented in the current MVP:

- OpenDyslexic-first bilingual interface;
- local PaddleOCR plain OCR for PDF/image documents, including multipage jobs;
- text-only paste and `.txt`/`.md` input;
- editable OCR blocks and accessible HTML/reading-text exports;
- long-document Edge-TTS chunking with Italian and English neural voices;
- separate LFM2.5 230M llama.cpp reflow with CPU/GPU selection and a strict
  non-whitespace content guard;
- offline Kokoro 82M ONNX speech and configurable Voxtral, Fish Audio, and
  ElevenLabs speech providers;
- local provider settings and consent-gated Voxtral/ElevenLabs cloning;
- authenticated local UI, persistent jobs, and private work-copy cleanup.
- resumable browser checkpoints, workflow recovery after machine restart, and
  audio playback-position restoration;
- OCR review controls for explicit block reordering plus a warning when the
  source geometry suggests a multi-column layout.
- keyboard-friendly view navigation, model-list browsing, translated live
  regions, and static frontend accessibility regression checks;

Next validation work:

1. keyboard-only, NVDA, VoiceOver, and Orca test sessions;
2. chapter navigation for long audio;
3. Pocket TTS adapter and local voice-prompt cloning when its runtime is
  installed and validated on the target machine;
4. EPUB export after conformance and screen-reader testing;
5. tagged DOCX/PDF only after format-specific accessibility validation.

No format will be labelled accessible solely because it was generated by the
application.
