# Roadmap

Implemented in the current MVP:

- local PDF/image OCR with confidence;
- editable reading order and semantic roles;
- accessible HTML and clean reading text;
- Italian Kokoro speech with two voices and adjustable speed;
- authenticated local UI, persistent jobs, and work-copy cleanup.

Next validation work:

1. keyboard-only, NVDA, VoiceOver, and Orca test sessions;
2. explicit block reordering and multi-column layout warnings;
3. table editor and user-authored alternative text for meaningful images;
4. resume position and chapter navigation for long audio;
5. EPUB export after conformance and screen-reader testing;
6. tagged DOCX/PDF only after format-specific accessibility validation.

No format will be labelled accessible solely because it was generated by the
application.
